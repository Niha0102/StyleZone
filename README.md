# 🛍️ StyleZone

### Full-Stack Fashion E-Commerce Web Application

StyleZone is a full-stack fashion e-commerce web application developed using **Python, Django, MySQL, HTML, CSS, and JavaScript**.

The project provides a complete shopping flow from user login and product browsing to cart, checkout, and order management, with a responsive design for desktop and mobile devices.

## 🌐 Live Website

**StyleZone:** https://style-zone-weld.vercel.app/

## 💻 GitHub Repository

* User Registration and Login

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Niha0102/StyleZone.git
cd StyleZone
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure MySQL

Create a MySQL database named:

```text
style_zone
```

Configure the database credentials in the project's environment settings.

### 6. Run Django

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
